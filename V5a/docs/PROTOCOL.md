# V4 experimental protocol

## 1. Canonical audit artifact

The canonical artifact is `experiments/reference_audit/reference_audit.json`,
generated by `scripts/run_reference_audit.py`. The old `scripts/run_audit.py`
is a deprecated compatibility wrapper.

## 2. Execution protocol

1. Validate disjoint `tune`, `validation`, and `test` seed pools.
2. Use the same `(scenario, seed)` for paired conditions.
3. Freeze the test YAML and record its SHA-256 before collecting results.
4. Compute physical metrics from true plant state; exclude wall-clock timing.
5. Report Wilson, paired Wilcoxon, McNemar, Holm correction, and Cliff's delta.
6. Describe the scheduler certificate as a numerical discrete-time certificate,
   not a formal proof or physical stability guarantee.

## 3. Release gates

A release requires the MRAC numerical sanity gate, discrete scheduler stability,
the MATLAB branch-shift and tolerance gates, three temporal readings,
speed-dependent zeta, documented sampling mismatch, and MRAC reference-model
Hurwitz/positive-Lyapunov checks.

`adaptation_superiority_demonstrated` is scientific, not a release gate. If it
is false, the paper must state that adaptation did not demonstrate superiority
in the configured experiment.
